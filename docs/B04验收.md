# B04 个人经历素材库 · 验收说明

对应分工表条目：**B04 个人经历素材库** —— 新增、编辑、搜索、删除经历；标明本人确认的事实与模拟情境。
旧系统参考：`coaching/CoachService.java`（`saveStory` / `manualStory` / `editStory` / `deleteStory`）、`CoachApp.tsx` 的素材页。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/preparation/stories` | 新增素材，返回 201 |
| GET | `/api/v1/preparation/stories?keyword=&source=` | 列出并搜索本人素材 |
| GET | `/api/v1/preparation/stories/{storyId}` | 查看本人单条素材 |
| PATCH | `/api/v1/preparation/stories/{storyId}` | 编辑标题、内容、来源、岗位、标签 |
| PATCH | `/api/v1/preparation/stories/{storyId}/confirmation` | 确认或撤销「本人确认的事实」 |
| DELETE | `/api/v1/preparation/stories/{storyId}` | 删除本人素材，返回 `{deletedId}` |

## 验收点

1. **新增 / 编辑 / 搜索 / 删除齐全**：四种操作都有独立接口与前端按钮；搜索命中标题、内容、岗位与标签，并支持按来源过滤。
2. **标明本人确认的事实与模拟情境**：素材来源只有 `SELF`（本人经历）与 `SCENARIO`（模拟情境）两种；`SELF` 默认是「本人经历（待核对）」，本人调用确认接口后才变成「本人确认的事实」；`SCENARIO` 永远是「模拟情境（公开案例推演）」，调用确认接口返回 409「模拟情境不能标记为本人确认的事实，请先把它改成本人真实经历」。
3. **来源改成模拟情境时自动撤销确认**：避免一条素材同时带着「模拟情境」和「本人确认」两个矛盾标记。
4. **只允许本人访问**：列表、搜索、详情、编辑、确认、删除都按账号归属校验；他人访问返回 403「这条经历素材属于其他账号，不能查看或修改」，不存在返回 404「经历素材不存在」。
5. **不写入真实简历**：素材内容由本人主动填写，后端只做长度校验（标题 2～60 字、内容 5～4000 字、标签最多 8 个），不抓取、不推断任何简历原文。

## 测试证据

`backend/src/test/java/com/chengjing/preparation/StoryLibraryTest.java`，三个用例：

- `keepsOwnStorySeparateFromSimulatedScenario`：本人经历确认前后标记变化；模拟情境确认返回 409。
- `editsSearchAndDeletesOwnStories`：编辑标题与标签不影响内容；搜索命中标题 / 岗位 / 标签；删除后列表减少。
- `rejectsOtherAccountsAndInvalidInput`：其他账号列表为空、详情与修改删除 403；缺来源、来源非法、内容过短分别返回明确 400；不存在返回 404。

本机已执行：`javac` 编译主代码与测试代码通过；前端 `tsc -b` 类型检查通过。完整 Maven 构建与测试未在本机执行。
