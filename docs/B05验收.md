# B05 单题专项练习 · 验收说明

对应分工表条目：**B05 单题专项练习** —— 从深挖节点挑一道题单独练；草稿随时保存，历次文字回答都留档。
旧系统参考：`coaching/CoachService.java`（`startPractice` / `saveDraft` / `submitAnswer` 三段式）、`CoachApp.tsx` 的练习页。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/preparation/plans/{planId}/nodes/{nodeId}/practices` | 从节点发起练习，返回 201 |
| GET | `/api/v1/preparation/practices` | 列出本人全部练习 |
| GET | `/api/v1/preparation/practices/{practiceId}` | 查看本人单次练习 |
| PATCH | `/api/v1/preparation/practices/{practiceId}` | 保存草稿 |
| POST | `/api/v1/preparation/practices/{practiceId}/answers` | 提交一次回答，返回 201 |
| DELETE | `/api/v1/preparation/practices/{practiceId}` | 删除本人练习，返回 `{deletedId}` |

## 验收点

1. **题目来自本人计划的深挖节点**：发起练习时按 `planId` + `nodeId` 定位节点，题目取节点自身的问题；节点不存在返回 404「深挖节点不存在，请先在深挖地图里生成节点」，他人的计划一律 403。
2. **草稿随时保存**：`PATCH` 只写草稿，最多 4000 字；草稿与已提交的回答分开存放，保存草稿不会覆盖任何一份历史回答。
3. **历次回答都留档**：每提交一次追加一条回答记录并带递增 `revision`，旧回答不删除；`view` 同时返回 `answers` 与 `status`（有回答为「已提交回答」，没有为「草稿中」）。提交成功后草稿清空，避免下次进入看到旧内容误以为没交。
4. **提交失败不丢草稿**：回答长度不足 2 字或超过 4000 字时返回 400，且草稿原样保留，用户可以继续改。
5. **重复提交有幂等保护**：请求带 `requestId` 时，同一次提交重复到达只产生一份回答；同一个 `requestId` 配不同文本返回 409「这次提交已经保存了另一份回答，请刷新查看后再重新提交」。
6. **同一节点重复进入复用原练习**：再次从同一节点发起时返回已有练习，连同其中的草稿与历史回答，不会因为多进一次页面就多出一条练习。
7. **只允许本人访问**：列表、详情、保存草稿、提交回答、删除都按账号归属校验；他人访问返回 403「这条练习记录属于其他账号，不能查看或修改」，不存在返回 404「练习记录不存在」。

## 测试证据

`backend/src/test/java/com/chengjing/preparation/PracticeTest.java`，五个用例：

- `asksTheNodeQuestionAndKeepsEverySubmittedAnswer`：发起练习取到节点题目；连续提交两次得到两条回答且 `revision` 递增；提交后草稿清空。
- `keepsTheDraftWhenSubmittingFails`：回答过短返回 400，草稿仍在且内容未变。
- `repeatedRequestIdDoesNotCreateASecondAnswer`：同一 `requestId` 重复提交只留一条回答；换文本复用同一 `requestId` 返回 409。
- `reopeningTheSameNodeReusesThePracticeAndKeepsItsDraft`：第二次从同一节点发起返回同一 `practiceId`，草稿与历史回答都还在。
- `rejectsOtherAccountsAndMissingNodes`：其他账号列表为空、详情与提交 403；不存在的节点返回 404；草稿超长返回 400。

本机已执行：`javac` 编译主代码与测试代码通过；前端 `tsc -b` 类型检查通过。完整 Maven 构建与测试未在本机执行。

## 模块影响

- 新增文件全部位于 `com.chengjing.preparation` 与 `frontend/src/features/preparation`，未改动其他成员模块。
- 前端新增 `PreparationPractices` 页面并挂到深挖地图每个节点的「练这道题」入口；草稿同时写入 `localStorage`，提交失败时页面提示并保留内容。
