# B02 岗位准备计划

选择岗位创建个人计划，列表只显示本人计划，别人的计划一律返回 403。计划可记录 B01 情境目录的 ID，本模块只保存引用，不复制案例内容。

接口（均返回 ApiResponse）：
- POST /api/v1/preparation/plans：创建计划，201；岗位 2～40 字、名称 2～60 字、目标 5～200 字、岗位要求最多 2000 字。
- GET /api/v1/preparation/plans：只列出本人计划，最近更新在前。
- GET /api/v1/preparation/plans/{id}：本人计划详情，不存在 404，他人 403。
- PATCH /api/v1/preparation/plans/{id}：只修改传入的字段；状态仅接受 PLANNING、READY、ARCHIVED。
- DELETE /api/v1/preparation/plans/{id}：删除本人计划，返回 deletedId。

归属规则：计划带账号 ID，读取与修改都要先过归属校验，因此列表和详情都拿不到别人的计划。
账号来源是 PreparationUserPort；A02 身份模块合并前，兜底实现返回 503 并提示「当前用户接口尚未配置，请完成 A02 身份模块连接」，不放行没有归属的数据。

关联旧系统：参考 coaching/CoachController.java 与 coaching/CoachService.java 的计划创建、列表与归属校验思路，按新模块结构重写为类型化的 PreparationPlan + PlanNode，未复制账号与评分代码。

## 可重复验收

1. 启动前后端，进入 /modules/preparation/plans，填写「后端工程师 / 秋招后端准备 / 在四十分钟里讲清一次真实的取舍和验证」。
2. 创建后列表只出现这一条，状态显示「准备中」；刷新页面仍在。
3. 点「标记为可练习」，状态变为「可练习」，岗位与情境引用保持不变。
4. 换一个账号请求该计划的详情、修改、删除，均返回 403「这条准备计划属于其他账号，不能查看或修改」；列表里也看不到它。
5. 删除后详情返回 404「准备计划不存在」；名称少于 2 字或目标少于 5 字时创建返回 400。

后端 PreparationPlanTest 覆盖：创建后列表仅本人可见（hasSize(1) 且 scenarioId 正确）、他人列表为空、他人 GET/PATCH/DELETE 全部 403、名称过短 400、目标过短 400、未知计划 404、状态大小写归一为 READY、删除后 404。

前端入口 /modules/preparation/plans：选择岗位、填写名称与目标即可创建，可填公开岗位要求，支持改状态、删除、加载失败重试；页面底部注明「只有你自己的账号能看到它」。

对其他模块的影响：只新增 preparation 包内文件与一条前端路由；App.tsx 新增 /modules/preparation/plans 一行，不改动 shared/ApiResponse、assessment 评分与已有模块入口。

后续依赖：情境下拉在 B01 的 /api/v1/preparation/scenarios 合并后自动生效（本页已按该接口调用，未合并时该请求失败只影响下拉，不影响创建与列表）；账号接入只需提供一个 PreparationUserPort 实现 Bean。
