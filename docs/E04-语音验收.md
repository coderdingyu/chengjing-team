# E04 传统语音转写与朗读验收

启动前后端后打开 `/voice-lab`。这个组件使用浏览器提供的语音转写和朗读能力，作为原生 Live 以外的常规语音练习入口；浏览器不支持语音识别时，文字草稿仍可使用。

1. 不勾选同意项时，“开始回答”不可用；点击“朗读题目”能播放题目，播放期间不能开始收音。
2. 勾选同意并授权麦克风后，说一段话；识别中的文字和定稿文字分开显示。定稿后可在文本框修改，再点击“将文字加入回答”。
3. 结束转写、关闭页面或切换路由后，识别会停止；刷新后没有原始音频或自动提交的回答。拒绝麦克风权限时显示错误，已经确认的文字不丢失。
4. 使用不支持 Web Speech Recognition 的浏览器时显示可读提示，仍能在草稿框手动输入。

应用代码不录制、上传或保存原始音频。浏览器自己的语音服务可能处理麦克风数据，因此界面在采集前明确告知并取得同意。接入 C 模块时复用 `VoicePanel` 的 `onConfirm` 回调，把用户确认后的文字写入该房间草稿。
