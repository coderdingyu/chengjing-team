# B01 岗位情境目录

提供 11 类岗位，各有公开模拟情境和准备目标。不包含真实简历，不需要登录即可浏览。

接口均使用既有 ApiResponse：
- GET /api/v1/preparation/roles：岗位列表。
- GET /api/v1/preparation/scenarios?role=前端工程师：按岗位筛选，省略岗位返回全部，未知岗位返回空列表。
- GET /api/v1/preparation/scenarios/{id}：情境详情，不存在返回 404。

前端入口 /modules/preparation，支持筛选、详情、加载和失败重试。App.tsx 仅新增该模块的明确路由，不改变其他模块入口或共享 API。

参考旧系统 ScenarioCatalog.java 与 resources/cases/additional.json 的岗位分类和模拟案例设计；按新模块结构重新实现类型化目录，不复制账号、评分或其他业务代码。

## 可重复验收

1. 启动前后端，打开面试准备，全部岗位展示 11 个案例。
2. 选择前端工程师，仅显示该岗位；打开详情，查看模拟情境及准备目标。
3. 切回全部岗位，确认案例恢复；每个岗位均可展开。
4. 停止后端后切换岗位，显示错误及重试按钮；恢复后端，重试成功。
5. 后端 ScenarioControllerTest 覆盖 11 类目录、全部详情、模拟标识、筛选和 404。
