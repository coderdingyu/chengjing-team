# E05 原生 Live 双向语音验收

这一项提供阶跃 StepAudio 3 Realtime 的服务端 WebSocket 桥接、一次性连接票据、浏览器 PCM 采集和播放、手动打断以及按用户保存的文字记录。Step 5 Preview 是文本模型，不能用于 Live；请在“模型配置”另建 `stepaudio-3-realtime-preview` 并绑定到“实时语音”。

自动验收：在 `backend` 运行 `./mvnw.cmd -s .mvn/settings.xml test`，其中 `LiveTicketServiceTest` 验证票据仅能使用一次、不同账号不能读记录、文字在重建服务后仍可读取，且对外票据不暴露模型密钥；在 `frontend` 运行 `npm run build`。

持有有效阶跃实时语音权限的账号可做人工端到端验收：

1. 登录后配置阶跃模型，进入 `/live-lab`。未勾选同意时无法连接；无 Live 路由时得到明确错误。
2. 点击开始后，面试官先提出一个完整问题；在面试官播放期间直接说话，不应自动截断问题。说完后浏览器开始送入候选人声音并显示转写文字。
3. 点击“手动打断”，播放立即停止，可以继续说。断开连接后文字记录仍在；点击继续应读回同一场文字记录。点击“开始新一场”生成新的会话。
4. 拒绝麦克风权限、断网和模型服务错误均应保留已保存的文字。后台数据库只保存岗位和定稿文本，不保存 PCM 音频。

浏览器通过先登录取得一次性票据，再用票据连接 `/ws/platform/live`；模型 API Key 仅在后端解密并传给阶跃。Live 票据与文字记录依赖 A02 身份模块合并后的登录会话。当前自动测试不代替具备模型权限时的实际音频验收。
